# rapcoding

Голосовой ввод текста для Windows. Говорите в микрофон — программа печатает
сказанное в том окне, где стоит курсор.

## Зачем это нужно

- Диктовка быстрее набора: тексты, письма, комментарии к коду, промпты для
  нейросетей.
- Работает в любой программе без плагинов и интеграций: редактор, браузер,
  чат, терминал.
- Распознавание полностью локальное: звук не уходит в интернет, не нужен
  аккаунт, ничего не стоит денег.
- Скорость: примерно секунда после того, как отпустили кнопку.

## Преимущества перед другими инструментами

Что обычно используют для голосового ввода: встроенную диктовку Windows
(Win+H), голосовой ввод Gboard, GUI-программы на Whisper, облачные
ассистенты. Чем rapcoding отличается:

- **Минимализм.** Нет окна, кнопок и меню. Один фоновый процесс и одна
  комбинация клавиш. Поставил, запустил, забыл. Остальные инструменты — это
  приложения с интерфейсом, окнами, настройками и подписками.
- **Ввод в любое текстовое поле.** Текст печатается на уровне системы — так
  же, как если бы его набирал человек с клавиатуры. Поэтому работает везде:
  редакторы, терминалы, браузеры, чаты. Без плагинов и интеграций под каждую
  программу. Многие GUI-распознавалки пишут только в своё окно или копируют
  в буфер.
- **Крошечный размер.** Сама программа ~600 КБ. Распознаватель и модель
  лежат отдельными файлами и в программу не вшиты. Для сравнения: программы,
  которые таскают модель внутри, весят сотни мегабайт.
- **Локально и приватно.** Звук с микрофона не покидает компьютер. Нет
  аккаунта, подписки и API-ключей. Встроенная диктовка Windows и Gboard
  отправляют ваш голос на серверы Microsoft/Google — rapcoding не отправляет
  его никуда.
- **Заточено под код и промпты.** Голосовые команды для скобок, переносов
  строк, двоеточий — то, чего нет в обычных диктовках.

Честная оговорка: по качеству распознавания локальная модель уступает
облачным гигантам (Google/Microsoft). Это цена за скорость, приватность и
отсутствие сети. Подробнее — в разделе «Два распознавателя» ниже.

## Как это работает

Программа висит в фоне и ждёт одну комбинацию клавиш.

1. Зажимаете `Ctrl+Alt+Space`. Комбинация глобальная — работает, даже если
   программа не в фокусе.
2. Говорите в микрофон. Программа записывает звук.
3. Отпускаете `Ctrl+Alt+Space`. Запись останавливается.
4. Звук передаётся распознавателю речи (Vosk). Через секунду готовый текст
   печатается в активном окне — туда, где стоит курсор.

Это всё. Окон, кнопок и меню нет: запустили один раз и пользуетесь хоткеем.

## Установка

Нужен Windows 10/11 и Rust (https://rustup.rs).

1. Соберите программу:

   ```
   cargo build --release
   ```

   Готовый файл: `target/release/rapcoding.exe`

2. Скачайте движок распознавания (~15 МБ):

   https://github.com/alphacep/vosk-api/releases/download/v0.3.45/vosk-win64-0.3.45.zip

   Распакуйте архив и положите **все DLL из него** рядом с `rapcoding.exe`
   (в ту же папку). Без них программа не запустится.

3. Скачайте модель русского языка (~46 МБ):

   https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

   Распакуйте в `%APPDATA%\rapcoding\models\`
   (в проводнике вставьте `%APPDATA%` в адресную строку).
   Должно получиться:
   `%APPDATA%\rapcoding\models\vosk-model-small-ru-0.22\`

4. Проверьте, что всё нашлось:

   ```
   rapcoding check
   ```

   В конце должно быть `all checks passed`.

5. Запустите:

   ```
   rapcoding run
   ```

   При первом запуске создастся файл настроек:
   `%APPDATA%\rapcoding\config.toml`

## Как пользоваться

1. Откройте программу, куда хотите вставить текст. Кликните в нужное место.
2. Зажмите `Ctrl+Alt+Space`, говорите, отпустите.
3. Через секунду текст появится в точке курсора.

Важно: текст печатается в окно, которое активно **в момент вставки**. После
того как отпустили хоткей, не переключайтесь на другие окна, пока текст не
появился.

Остановить программу: `Ctrl+C` в её окне.

## Выбор микрофона

Самому ничего выбирать не нужно: по умолчанию берётся системный микрофон —
тот, что выбран в Windows (Параметры → Система → Звук → Ввод).

Если системный микрофон — не тот, что нужно, два способа:

1. Поменять устройство по умолчанию в настройках Windows.
2. Или указать нужный в конфиге. Сначала посмотрите список устройств:

   ```
   rapcoding devices
   ```

   Впишите часть названия нужного микрофона в `audio.device`:

   ```toml
   device = "микрофонов"
   ```

   Программа возьмёт первый микрофон, в названии которого есть эта строка
   (регистр не важен). Если строка ни с чем не совпадёт — программа при старте
   упадёт с ошибкой, а не будет молча писать в тишину.

   После смены конфига перезапустите `rapcoding run` — конфиг читается один
   раз при старте.

Частота и каналы подстраиваются сами: берётся родной формат устройства
(например, 48 кГц стерео), внутри программа сводит в моно и пересчитывает в
16 кГц — это нужно распознавателю.

Предупреждение: бывает, что системным дефолтом стоит «Стерео микшер» — это
петля, которая пишет звук из динамиков, а не голос. Тогда диктовка будет
«слышать» тишину. Лечится выбором настоящего микрофона (способ 1 или 2).

## Настройки

Файл `%APPDATA%\rapcoding\config.toml`. Что меняют чаще всего:

| Настройка                | Что делает                                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| `general.hotkey`         | комбинация клавиш, например `"ctrl+alt+space"` или `"f9"`                                                |
| `general.mode`           | `"hold"` — запись, пока держите кнопку; `"toggle"` — первое нажатие включает запись, второе выключает    |
| `asr.backend`            | `"vosk"` — быстро (~1 с), только русский; `"sidecar"` — Whisper, смесь русского и английского, медленнее |
| `asr.model`              | путь к модели распознавания                                                                              |
| `inject.method`          | `"type"` — печатает текст напрямую; `"paste"` — через буфер обмена                                       |
| `text.strip_punctuation` | `true` — убирать знаки препинания, оставлять только слова                                                |

## Два распознавателя: vosk и whisper

По умолчанию стоит vosk:

- **Vosk**: русский язык, ~1 секунда на фразу. Английские слова при этом
  распознаются плохо.
- **Whisper**: понимает смесь русского и английского в одной фразе. Минус —
  на слабом ноутбучном процессоре фраза обрабатывается ~9 секунд, на обычном
  десктопе быстрее.

Если нужна смесь языков: поставьте `backend = "sidecar"`,
`model = "models/ggml-small-q5_1.bin"`, а `whisper-cli` (из архива whisper.cpp)
положите в PATH. Модель Whisper качается отсюда:
https://huggingface.co/ggerganov/whisper.cpp (файл `ggml-small-q5_1.bin`).

## Голосовые команды

Говорите команду — печатается символ вместо слов:

| Говорите          | Появится                   |
| ----------------- | -------------------------- |
| новая строка      | перенос строки (как Enter) |
| новый абзац       | пустая строка              |
| открыть скобку    | `(`                        |
| закрыть скобку    | `)`                        |
| точка с запятой   | `;`                        |
| двойное двоеточие | `::`                       |
| new line          | перенос строки             |
| open parenthesis  | `(`                        |

По умолчанию работают только такие фразы из нескольких слов — их не спутаешь
с обычной речью. Режим `"aggressive"` добавляет одиночные слова: «запятая»
печатает запятую, «равно» — знак равенства. Минус: слово «запятая» в обычной
фразе тоже превратится в знак.

## Ограничения

- **Окна администратора.** Если целевая программа запущена от имени
  администратора, а rapcoding — нет, Windows заблокирует ввод (защита UIPI).
  Решение: запускать rapcoding тоже от имени администратора.
- **macOS.** Система требует разрешение Accessibility для имитации набора,
  а обработчик хоткея должен работать в главном потоке — это ещё не
  реализовано. Программа собирается, но на macOS не проверялась.
- **Linux.** Работает только в окружении X11. В Wayland глобальные хоткеи
  запрещены системой.

## Карта проекта (для разработчиков)

Входная точка — `src/main.rs`: CLI, цикл событий, пайплайн фразы.

```
src/main.rs        CLI + цикл событий + пайплайн фразы
src/audio.rs       захват микрофона (cpal): downmix, resample 48к→16к, обрезка тишины
src/asr.rs         бэкенды распознавания: SidecarAsr (whisper-cli) | VoskAsr (vosk-rs)
src/inject.rs      вставка: type (enigo, прямой ввод) | paste (arboard + хорда)
src/text.rs        постобработка: звуковые теги, голосовые команды, пунктуация
src/hotkey.rs      global-hotkey + Win32 message pump, hold/toggle
src/config.rs      TOML-конфиг, дефолты, валидация
src/wav.rs         WAV: запись/чтение (16 кГц PCM)
src/log.rs         лог с ротацией (5 МБ)
src/error.rs       единый тип ошибок
assets/config.toml канонический шаблон конфига
build.rs           link-search для libvosk.lib
lib/vosk/          libvosk.lib (линковка на Windows)
```

Поток данных на фразу: hotkey → AudioCapture (48 кГц моно) → resample 16 кГц →
trim_silence → AsrBackend → postprocess → Injector → активное окно.

Ключевые зависимости: cpal, global-hotkey, crossbeam-channel, enigo, arboard,
serde, toml, thiserror, vosk (+ windows-sys под Windows).

Сборка и проверка:

```
cargo build --release   # бинарь ~600 КБ
cargo test              # 33 теста
rapcoding check         # проверка окружения
```

Нюансы реализации:

- Vosk: модель грузится один раз при старте демона и живёт в памяти
  (~1 с на фразу).
- Whisper: sidecar-процесс на каждую фразу (медленнее, зато RU/EN).
- `libvosk.dll` и зависимые DLL должны лежать рядом с exe; `libvosk.lib` нужен
  только при линковке.
- Аудио-колбэк lock-free (crossbeam): мьютекс и аллокации в real-time колбэке
  дают WASAPI buffer underrun.
- Конфиг читается один раз при старте; смена настроек требует рестарта.

Release-профиль: `opt-level="z"`, `lto="fat"`, `codegen-units=1`,
`panic="abort"`, `strip=true`.

## Остальное

- Распознавание локальное: звук с микрофона никуда не отправляется.
- Сказанный текст не пишется в логи (если не включить `log_transcripts`).
- Сама программа занимает ~600 КБ. Распознаватель и модель лежат отдельными
  файлами и в программу не вшиты — поэтому их и нужно скачивать отдельно.
