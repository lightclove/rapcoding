# rapcoding

Голосовой ввод текста для Windows. Говорите в микрофон — программа печатает
сказанное в том окне, где стоит курсор.

## Зачем это нужно

- Диктовка быстрее набора: тексты, письма, комментарии к коду, промпты для
  нейросетей.
- Работает в любой программе без плагинов и интеграций: редактор, браузер,
  чат, терминал.
- Распознавание полностью локальное: звук не уходит в интернет, не нужен
  аккаунт, бесплатно.
- Скорость: примерно секунда после того, как отпустили кнопку.

## Преимущества перед другими инструментами

Что обычно используют для голосового ввода: встроенную диктовку Windows
(Win+H), голосовой ввод Gboard, GUI-программы-распознавалки, облачные
ассистенты. Вот чем rapcoding отличается:

- **Минимализм.** По умолчанию — фоновый процесс без окна: две комбинации
  клавиш (русская и английская), поставил, запустил, забыл. Кому нужен
  интерфейс — есть опциональный GUI (темы, лог, журнал, загрузка моделей).
  Остальные инструменты — это приложения с окнами, настройками и подписками.
- **Ввод в любое текстовое поле.** Текст печатается на уровне системы — так
  же, как если бы его набирал человек с клавиатуры. Поэтому работает везде:
  редакторы, терминалы, браузеры, чаты. Без плагинов и интеграций под каждую
  программу. Многие GUI-распознавалки пишут только в своё окно или копируют
  в буфер.
- **Локально и приватно.** Звук с микрофона не покидает компьютер. Нет
  аккаунта, подписки и API-ключей. Встроенная диктовка Windows и Gboard
  отправляют ваш голос на серверы Microsoft/Google — rapcoding не отправляет
  его никуда.
- **Заточено под код и промпты.** Голосовые команды для скобок, переносов
  строк, двоеточий — то, чего нет в обычных диктовках.

Честная оговорка: локальные модели понимают русский и английский по
отдельности (каждый язык — свой хоткей и своя модель), а смесь в одной фразе
не распознаётся. По качеству они уступают облачным гигантам
(Google/Microsoft). Это цена за скорость, приватность и отсутствие сети.

## Как это работает

Программа висит в фоне и ждёт две комбинации клавиш — русскую и
английскую.

1. Зажимаете `Ctrl+Alt+Space` (русский) или `Ctrl+Win+Alt+Space` (английский).
   Комбинации глобальные — работают, даже если программа не в фокусе.
2. Говорите в микрофон. Программа записывает звук.
3. Отпускаете комбинацию. Запись останавливается.
4. Звук передаётся распознавателю речи (Vosk). Через секунду готовый текст
   печатается в активном окне — туда, где стоит курсор.

Это всё. В консольном режиме окон нет: запустили один раз и пользуетесь
хоткеями. Хотите видеть статус, лог и управлять моделями — запустите GUI
(см. «Графический интерфейс»).

## Установка

Нужен Windows 10/11 и Rust (https://rustup.rs).

1. Соберите программу:

   ```
   cargo build --release                  # консольный режим (без окна)
   cargo build --release --features gui   # + графический интерфейс
   ```

   Готовый файл: `target/release/rapcoding.exe`

2. Скачайте движок распознавания (~15 МБ):

   https://github.com/alphacep/vosk-api/releases/download/v0.3.45/vosk-win64-0.3.45.zip

   Распакуйте архив и положите **все DLL из него** рядом с `rapcoding.exe`
   (в ту же папку). Без них программа не запустится.

3. Скачайте модель русского языка (~46 МБ):

   https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

   Распакуйте в `%APPDATA%\rapcoding\models\`
   (в проводнике вставьте `%APPDATA%` в адресную строку).
   Должно получиться:
   `%APPDATA%\rapcoding\models\vosk-model-small-ru-0.22\`

4. Если нужен английский хоткей — модель английского (~40 МБ):

   https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip

   Распакуйте туда же:
   `%APPDATA%\rapcoding\models\vosk-model-small-en-us-0.15\`

5. Проверьте, что всё нашлось:

   ```
   rapcoding check
   ```

   В конце должно быть `all checks passed`.

6. Запустите:

   ```
   rapcoding run
   ```

   При первом запуске создастся файл настроек:
   `%APPDATA%\rapcoding\config.toml`

### Установщик (Windows)

Есть готовый установщик — `installer/rapcoding.iss` (Inno Setup). Ставит в
`%LOCALAPPDATA%\Programs\rapcoding`, без прав администратора. Сборка в два
шага (нужен Rust + cargo и Inno Setup):

```
powershell -NoProfile -ExecutionPolicy Bypass -File installer\build.ps1
ISCC.exe installer\rapcoding.iss
```

`build.ps1` собирает обе версии (консольную и GUI) в `target\release\`.

Результат: `dist/RapcodingSetup-0.1.0.exe`. В установщике выбирается:

- **Версия** — галка «Графический интерфейс» (снята = только консоль).
- **Модели** — русская и английская, каждая лёгкая (~44/~39 МБ) или тяжёлая
  (~1.8 ГБ, точнее); качаются с прогресс-баром.

Модели скачиваются в `%APPDATA%\rapcoding\models\` (нужен интернет). Если
снять выбор или скачивание не удалось, модели кладутся вручную (шаги 3–4).
При удалении программы деинсталлятор предлагает галочку «Удалить
пользовательские данные и все скачанные модели» (стирает
`%APPDATA%\rapcoding`).

## Как пользоваться

1. Откройте программу, куда хотите вставить текст. Кликните в нужное место.
2. Зажмите `Ctrl+Alt+Space` — русская речь; `Ctrl+Win+Alt+Space` — английская.
3. Через секунду текст появится в точке курсора.

Смешивать языки в одной фразе нельзя: каждая комбинация держит свою модель.
Английская модель грузится лениво — при первом использовании EN-хоткея
добавится ~0,5 с на загрузку, дальше без задержки.

Важно: текст печатается в окно, которое активно **в момент вставки**. После
того как отпустили хоткей, не переключайтесь на другие окна, пока текст не
появился.

Остановить программу: `Ctrl+C` в её окне.

## Графический интерфейс

Сборка с `--features gui` добавляет окно. По умолчанию `gui.enabled = true`,
поэтому `rapcoding run` в GUI-сборке открывает окно; распознавание при этом
работает в фоне как обычно (демон крутится на отдельном потоке). Отключить
окно: `gui.enabled = false` в конфиге или флаг `--no-gui`. Флаг `--gui`
принудительно открывает окно даже при `gui.enabled = false` (только в сборке
с фичей; без фичи флаг `--gui` падает с ошибкой).

Что есть в окне:

- **Статус** — живой: «Готов» / «Слушаю (ru|en)» / «Распознаю» / «Ошибка».
- **Тема** — светлая (по умолчанию) / тёмная, переключается кнопкой и
  сохраняется в конфиг.
- **Модели** — список тяжёлых моделей (1.8–2.5 ГБ) с кнопкой «Скачать» и
  прогресс-баром; распаковываются в `%APPDATA%\rapcoding\models\<имя>\`.
- **Лог** — живой лог демона + кнопка «Экспорт…» (сохранить в файл).
- **Журнал** — история управления (старт сессии, смена темы, скачивания).

После скачивания нажмите «Сделать активной» у установленной модели и
перезапустите — модель станет активной.

## Выбор микрофона

Самому ничего выбирать не нужно: по умолчанию берётся системный микрофон —
тот, что выбран в Windows (Параметры → Система → Звук → Ввод).

Если системный микрофон — не тот, что нужно, два способа:

1. Поменять устройство по умолчанию в настройках Windows.
2. Или указать нужный в конфиге. Сначала посмотрите список устройств:

   ```
   rapcoding devices
   ```

   Впишите часть названия нужного микрофона в `audio.device`:

   ```toml
   device = "микрофонов"
   ```

   Программа возьмёт первый микрофон, в названии которого есть эта строка
   (регистр не важен). Если строка ни с чем не совпадёт — программа при старте
   упадёт с ошибкой, а не будет молча писать в тишину.

   После смены конфига перезапустите `rapcoding run` — конфиг читается один
   раз при старте.

Частота и каналы подстраиваются сами: берётся родной формат устройства
(например, 48 кГц стерео), внутри программа сводит в моно и пересчитывает в
16 кГц — это нужно распознавателю.

Предупреждение: бывает, что системным дефолтом стоит «Стерео микшер» — это
петля, которая пишет звук из динамиков, а не голос. Тогда диктовка будет
«слышать» тишину. Лечится выбором настоящего микрофона (способ 1 или 2).

## Настройки

Файл `%APPDATA%\rapcoding\config.toml` (создаётся при первом запуске;
можно заранее — командой `rapcoding init`). Что меняют чаще всего:

| Настройка                  | Что делает                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------------- |
| `general.hotkey`           | комбинация для русской модели, например `"ctrl+alt+space"` или `"f9"`                             |
| `general.en_hotkey`        | комбинация для английской модели (`"win"` = клавиша Win/Command)                                  |
| `general.mode`             | `"hold"` — запись, пока держите кнопку; `"toggle"` — нажатие включает запись, повторное выключает |
| `general.max_record_secs`  | аварийная остановка записи (секунды), чтобы не писать бесконечно                                  |
| `general.log_transcripts`  | `true` — писать распознанный текст в лог (по умолчанию выключено ради приватности)                |
| `audio.device`             | подстрока названия микрофона; пусто = системный по умолчанию                                      |
| `audio.silence_threshold`  | порог тишины (амплитуда 0.0..1.0); выше — речь                                                    |
| `audio.min_speech_ms`      | звук короче этого (мс) считается шумом и игнорируется                                             |
| `asr.model`                | путь к русской модели (директория Vosk); по умолчанию `models/...` относительно папки конфига     |
| `asr.en_model`             | путь к английской модели                                                                          |
| `text.voice_commands`      | `"off"` / `"safe"` (только многословные) / `"aggressive"` (добавляет однословные)                 |
| `text.strip_punctuation`   | `true` — убирать знаки препинания, оставлять только слова                                         |
| `inject.enabled`           | `false` — распознавать, но не вставлять (для отладки)                                             |
| `inject.method`            | `"paste"` — через буфер обмена (по умолчанию); `"type"` — печатать напрямую                       |
| `inject.paste_shortcut`    | хорда вставки; пусто = системная (`ctrl+v`); например `"ctrl+shift+v"` для терминалов             |
| `inject.restore_clipboard` | `true` — вернуть прежний буфер после вставки                                                      |

Секция `[gui]`: `enabled` (`true` — открывать окно, `false` — консольный
режим) и `theme` (`"light"` / `"dark"`). Актуально только в GUI-сборке
(`--features gui`).

## Ограничения

- **Окна администратора.** Если целевая программа запущена от имени
  администратора, а rapcoding — нет, Windows заблокирует ввод (защита UIPI).
  Решение: запускать rapcoding тоже от имени администратора.
- **macOS.** Система требует разрешение Accessibility для имитации набора,
  а обработчик хоткея должен работать в главном потоке — это ещё не
  реализовано. Программа собирается, но на macOS не проверялась.
- **Linux.** Работает только в окружении X11. В Wayland глобальные хоткеи
  запрещены системой.
- **Закрепление в панели задач.** Windows 10/11 запрещает программам молча
  закреплять себя; установщик делает best-effort попытку, и она может не
  сработать. Закрепить вручную: правый клик по ярлыку → «Закрепить на
  панели задач».

## Карта проекта (для разработчиков)

Входная точка — `src/main.rs`: CLI, цикл событий, пайплайн фразы.

```
src/main.rs        CLI + цикл событий + пайплайн фразы (две модели, два хоткея)
src/audio.rs       захват микрофона (cpal): downmix, resample до 16 кГц, обрезка тишины
src/asr.rs         распознавание: VoskAsr (vosk-rs); RU грузится при старте, EN — лениво
src/inject.rs      вставка: paste (arboard + хорда, по умолчанию) | type (enigo, прямой ввод)
src/text.rs        постобработка: звуковые теги, голосовые команды, пунктуация
src/hotkey.rs      global-hotkey + Win32 message pump, hold/toggle, алиас "win"
src/config.rs      TOML-конфиг, дефолты, валидация
src/wav.rs         WAV: запись/чтение (16 кГц PCM)
src/log.rs         лог с ротацией (5 МБ), санитизация управляющих символов
src/error.rs       единый тип ошибок
src/sync.rs        восстановление отравленных мьютексов (lock_recover)
src/status.rs      живой статус демона (Idle / Listening / Transcribing / Error)
src/journal.rs     журнал управления (append-only, RFC3339-таймстамп)
src/gui.rs         GUI (egui/eframe): окно, темы, лог, журнал, модели (за фичей `gui`)
src/download.rs    загрузчик моделей: streaming + zip + прогресс (за фичей `gui`)
assets/config.toml канонический шаблон конфига
assets/rapcoding.ico иконка приложения (вшивается в exe через winres)
installer/         Inno Setup: rapcoding.iss + pin-taskbar.ps1 (best-effort)
build.rs           link-search для libvosk.lib + встраивание иконки
lib/vosk/          libvosk.lib (линковка на Windows)
```

Поток данных на фразу: hotkey → AudioCapture (48 кГц моно) → resample 16 кГц →
trim_silence → VoskAsr (RU или EN, по хоткею) → postprocess → Injector →
активное окно.

Ключевые зависимости: cpal, global-hotkey, crossbeam-channel, enigo, arboard,
serde, toml, thiserror, vosk (+ windows-sys под Windows).

Сборка и проверка:

```
cargo build --release                # консольный режим: бинарь ~750 КБ
cargo build --release --features gui # GUI: бинарь ~4.5 МБ
cargo test                           # 56 тестов (консоль); --features gui → 72
rapcoding check                      # проверка окружения
ISCC.exe installer/rapcoding.iss     # установщик → dist/
```

CLI: `run` (демон, по умолчанию), `check`, `devices`, `transcribe <wav>`,
`inject <text>`, `init` (создать конфиг), `help`. Опции: `--config <path>`,
`--gui` (открыть окно), `--no-gui` (только консоль), `-v/--verbose`,
`-V/--version`, `-h/--help`; окружение: `RAPCODING_CONFIG`,
`RAPCODING_CONFIG_DIR`.

Нюансы реализации:

- Vosk: русская модель грузится при старте демона, английская — лениво, при
  первом нажатии EN-хоткея (экономия памяти, ~0,5 с разовой загрузки).
- `libvosk.dll` и зависимые DLL должны лежать рядом с exe; `libvosk.lib` нужен
  только при линковке.
- Аудио-колбэк lock-free (crossbeam): мьютекс и аллокации в real-time колбэке
  дают WASAPI buffer underrun.
- Конфиг читается один раз при старте; смена настроек требует рестарта.

Release-профиль: `opt-level="z"`, `lto="fat"`, `codegen-units=1`,
`panic="abort"`, `strip=true`.

## Остальное

- Распознавание локальное: звук с микрофона никуда не отправляется.
- Сказанный текст не пишется в логи (если не включить `log_transcripts`).
- Консольный бинарь ~750 КБ, GUI-сборка ~4.5 МБ. Распознаватель и модель
  лежат отдельными файлами и в программу не вшиты — поэтому их и нужно
  скачивать отдельно.
